# IFsaudavel 4.0

Site educativo do IFS Campus Lagarto (HTML + CSS + JS puros, sem build).

## Arquivos
- `index.html` — página inicial (hero com "Meu dia", pilares, ferramentas interativas, mito/verdade, checklist, FAQ, sobre)
- `quiz.html` + `quiz.js` — quiz com explicações e revisão
- `avaliacao.html` + `avaliacao.js` — avaliação (envia ao Google Sheets; URL no topo de `avaliacao.js`)
- `fontes.html` — fontes com filtro por tema
- `style.css`, `script.js`, `favicon.svg`, `404.html`

## Publicar no GitHub Pages
Envie todos os arquivos para a raiz do repositório → Settings → Pages → Deploy from a branch → `main` / `(root)`.

O conteúdo é educativo e não substitui orientação de profissionais de saúde.
